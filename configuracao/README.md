# Configuração do Sammy

- `configuracao-do-workflow.json`: política geral de execução.
- `politica-de-modelos.yaml`: estratégia de modelos, esforço e custo.
- `catalogo-de-modelos.json`: catálogo de aliases/modelos.
- `integracao-github.json`: política de integração com GitHub.

Consulte [configurações e implementação](../docs/README.md#configurações-e-implementação) e [gerenciamento de modelos](../docs/07-modelos/gerenciamento-de-modelos.md).
