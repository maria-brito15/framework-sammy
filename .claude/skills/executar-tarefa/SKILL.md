# Executar tarefa

1. Confirme `tarefas:aprovadas` e a identificação da tarefa.
2. Delegue ao implementador com escopo e arquivos permitidos.
3. Execute os testes pertinentes e registre comando, exit code e resumo.
4. Pare se a especificação for ambígua ou incompleta.
5. Não feche a tarefa sem evidência nova.
