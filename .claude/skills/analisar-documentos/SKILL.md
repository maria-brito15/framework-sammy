# Analisar documentos

- Leia fontes em `documentos/entrada/` e preserve os originais.
- Use o analista de requisitos e o analista de dados quando houver fontes pertinentes.
- Registre arquivo e página/seção para cada achado relevante.
- Separe fatos, inferências, propostas, premissas e questões em aberto.
- Identifique lacunas, contradições, regras de negócio e restrições.
- Não invente decisões.
- Gere `planejamento/diagnostico.md` a partir do template central.
- Atualize o estado para revisão, nunca para aprovado.
