# Planejar projeto

1. Verifique o gate do diagnóstico.
2. Acione arquiteto e planejador em paralelo somente se as entradas estiverem disponíveis e independentes.
3. Gere arquitetura, equipes e fases usando templates centrais.
4. Distinga decisões aprovadas de propostas.
5. Não invente equipe disponível, prazo ou orçamento.
6. Audite, corrija problemas mecânicos e salve como rascunho/em revisão.
7. Apresente um pacote único para aprovação humana.
